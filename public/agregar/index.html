Siguiente ID disponible. El nombre puede cambiar; el ID se mantiene.

El ZIP contiene la carpeta del counter con datos.json y su imagen. Descargarlo todavía no lo publica.

Publicarlo en tres pasos

  1. Descargá el ZIP y extraé la carpeta numerada.
  2. Abrí GitHub para agregar y arrastrá esa carpeta dentro de counters.
  3. Confirmá con “Commit changes”. La web se actualiza cuando termine el despliegue.

Solo quienes tengan permiso en el repositorio pueden guardar cambios. Esta página no requiere contraseña ni guarda tokens. Para editar o eliminar un counter, abrí su carpeta en GitHub.
